## ✨ Features

- **Episode Archive** — Pulls published episodes from Buzzsprout and displays them with search/filter
- **Patreon / Lodge** — Membership tier showcase for The Inner Circle
- **Games Page** — Interactive games for listeners
- **Recipes** — Paranormally perfect stews & brews
- **Merch Shop** — Curiosities, oddities & wares
- **Whispering Well** — Story submission form (listeners can submit paranormal tales for the show)
- **Audio Player** — In-page episode playback
- **Theme Switcher** — Light & dark mode
- **PWA Support** — Web app manifest for installability
- **SEO Component** — Per-page meta tag management
- **Accessibility** — Skip-to-content link, aria labels, jsx-a11y lint rules

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- Python 3.x (for episode fetching)

### Install & Run

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

### Fetch Episodes from Buzzsprout

Create a `.env` file in the project root:

```env
BUZZSPROUT_PODCAST_ID=your_podcast_id
BUZZSPROUT_API_TOKEN=your_api_token
```

Then run:

```bash
python fetch_episodes.py
```

This fetches all published episodes and writes them to `src/data/episodes.json`.
